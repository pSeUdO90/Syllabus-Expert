How it works

1
Read the PDF

PyMuPDF pulls reading-order text from each page of the question paper.

2
Parse MCQs

The heuristic matches Q1. / A. B. C. D. layouts used in NEET-style papers.

3
Map the key

An optional answer-key PDF fills letters and explanations onto the same question numbers.

4
Review and practice

Math is converted to LaTeX. You can edit the bank, then take the paper as a quiz.
